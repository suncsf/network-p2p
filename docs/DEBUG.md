# 本地调试 & 试用指南

## 一键启动（Linux，当前机器）

```bash
cd /home/umeall/文档/默认项目/network-p2p
ELECTRON_DISABLE_SANDBOX=1 npx electron-vite dev
```

启动后会看到：

- **主窗口**：左侧「工作区 / 服务端 / 设置」，右侧是连接选项卡。
- **悬浮球**：屏幕右下角圆形图标（可拖动），点击展开主窗口。

> 本机是 Wayland 桌面且缺少 GPU/沙箱支持，必须带 `ELECTRON_DISABLE_SANDBOX=1`
> 和 `--no-sandbox --disable-gpu`（已写进主进程的 Linux 兜底逻辑）。

## 3 分钟自测流程（单机即可完成）

### 1. 开一个服务端

1. 左侧点「服务端」→「启动服务」。
2. 记住「本机局域网 IP」（也可直接用 `127.0.0.1`）。
3. 切到「账户」→「新建账户」，填用户名，点「随机生成」得到密码并记下。
4. 在该账户下点「+ 添加目录」，填一个真实存在的目录绝对路径（例如 `/tmp/share`），
   勾选默认权限（至少 READ + UPLOAD + DOWNLOAD + TRANSFER），保存。

### 2. 用客户端连上去

1. 左侧点「工作区」→ 顶部选项卡「**新建连接**」。
2. 填 `127.0.0.1`、端口 `47100`、刚才的账号密码 → 连接。
3. 连接成功后会**新增一个选项卡**，里面可切「文件 / 传输」。

### 3. 验证多连接不冲突

重复第 2 步连另一个账户（或另一个服务端），会**再开一个选项卡**，
每个选项卡的目录、权限、状态互相独立。

- 右键选项卡或点 × 可断开该连接；
- 只关闭窗口不会退出程序，程序在托盘里。

### 4. 权限验证

- 在「服务端 → 账户 → 编辑权限树」把根目录设为只读，重新连接后
  「新建文件夹 / 上传 / 重命名 / 删除」按钮会变灰。
- 直接在目录树里对某个子目录做“覆盖权限”，验证继承规则。

## 常见问题

| 现象 | 处理 |
|---|---|
| 窗口打不开 / 白屏 | 确认带 `ELECTRON_DISABLE_SANDBOX=1` 启动 |
| 连接提示端口占用 | 服务端页点「自动选空闲端口」 |
| 悬浮球看不到 | 可能在多显示器/Workspace 上，点托盘图标可唤出主窗口 |
| 想彻底退出 | 托盘菜单 → 退出 |
