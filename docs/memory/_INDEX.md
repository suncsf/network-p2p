## 检索链路（n 年后提问时）

1. 本文件确定分片；拿不准时执行 `grep 关键词 docs/memory/_INDEX-*.md` 跨片检索
2. 在 _INDEX-<域>.md 中按关键词命中日期（行格式：`关键词|(年/月1|月2/日组1|日组2)`，跨年追加新括号组）
3. 进入 `YYYY/MM/DD/core.md` 看当日「关键词 → 记忆文件」映射
4. 打开 `<模块名>.md` 看详细内容

回答历史问题时必须主动走这条检索链路，不能只凭当前对话上下文回答。

## 维护规则

- 词汇分片只增不删；一词只进一片；关键词已存在则把新日期并入（升序），否则新增一行
- 新建任何分片后，必须回填上方「分片清单」
- 单个分片超过 80 行时拆出子域分片，并更新本清单
