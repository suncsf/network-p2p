# 软件更名

- 归档日期：2026-11-27
- 类型：需求开发（need）
- 来源：v-Lattice 项目会话（软件更名 v-Lattice）
- 梳理汇入时间：2026-11-27 10:37

## 用户提示词

> 软件名称叫：v-Lattice

## 实际需求梳理

软件对外名称由 "Lattice" 更名为 "v-Lattice"，所有用户可见的名称（窗口标题、托盘提示、界面品牌名、页面标题、打包产物名、包名、文档标题）同步更新。

## 需求/问题描述

项目此前统一叫 Lattice，用户明确软件名为 v-Lattice，需要改全部展示位。

## 解决方案

用户可见名称全部改为 v-Lattice，共 9 处文件：

| 位置 | 修改 |
| --- | --- |
| `src/main/index.ts` | 主窗口 `title: 'v-Lattice'`、托盘 `setToolTip('v-Lattice')` |
| `src/renderer/index.html` | `<title>v-Lattice</title>` |
| `src/renderer/floater.html` | `<title>v-Lattice Floater</title>` |
| `src/renderer/src/main/App.vue` | 侧边栏品牌 `<span>v-Lattice</span>` |
| `package.json` / `package-lock.json` | 包名 `v-lattice`、description、author.name |
| `electron-builder.yml` | `productName: v-Lattice`、copyright、maintainer（产物名变为 `v-Lattice-0.1.0-*`） |
| `README.md` | 文档标题 `# v-Lattice` |

**有意保留不动的（避免破坏数据/升级路径）：**

- `app.setName('lattice')` 与 userData 下 `lattice.db` / `local.db`：改名会切换数据目录，导致已有账户、连接历史、传输记录全部"丢失"。
- 内部类名 `LatticeServer` / `LatticeClient`：纯代码标识，不影响显示。
- `appId: com.lattice.app`：改了会被系统视为另一个应用，影响已装版本的覆盖安装。

## 涉及文件

`src/main/index.ts`、`src/renderer/index.html`、`src/renderer/floater.html`、`src/renderer/src/main/App.vue`、`package.json`、`package-lock.json`、`electron-builder.yml`、`README.md`

## 代码变更摘要

纯名称替换，无逻辑变更。另：本会话内 package-lock.json 的两处 `"name": "lattice"` 同步改为 `"name": "v-lattice"`（shell 转义失败后改用编辑工具 replaceAll 完成）。
