# 移除应用菜单

- 归档日期：2026-11-27
- 类型：需求开发（need）
- 来源：v-Lattice 项目会话（去除 Electron 默认菜单）
- 梳理汇入时间：2026-11-27 10:37

## 用户提示词

> 去除上方的electron自带菜单

## 实际需求梳理

去掉主窗口顶部 Electron 默认生成的应用菜单栏（File/Edit/View 等），界面更干净；不得影响项目里自定义的托盘右键菜单和悬浮球右键菜单。

## 需求/问题描述

Electron 应用默认自带应用菜单（含 File/Edit/View，附带 Ctrl+Shift+I DevTools、Ctrl+R 刷新等快捷键），本项目的 UI 无边框风格下不需要它。

## 解决方案

在 `src/main/index.ts` 的 `app.whenReady()` 回调最开头加一行：

```ts
Menu.setApplicationMenu(null)
```

- 对 Windows / Linux 均生效，主窗口顶部菜单栏消失。
- 不影响 `Menu.buildFromTemplate(...)` 单独构建的托盘菜单（createTray）与悬浮球菜单（window:floaterMenu），`setApplicationMenu` 只管"应用菜单"。
- 副作用：默认菜单里的 DevTools（Ctrl+Shift+I）与刷新（Ctrl+R）快捷键随之失效；开发期仍可通过 attachDebug 打开 DevTools。

## 涉及文件

- `src/main/index.ts`（app.whenReady 开头新增 1 行 + 注释）

## 代码变更摘要

`Menu.setApplicationMenu(null)`，1 行。
