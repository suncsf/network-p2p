# 服务端当前连接

## 用户提示词（原话，一字不改）

> 新增服务端中当前连接列表

> 总结归档

## 实际需求梳理

1. 服务端面板（ServerView）新增「当前连接」视图：实时展示当前登录本机服务端的客户端列表（账户、来源 IP、登录时间、最近活跃）。
2. 客户端登录/断开时列表自动刷新，无需手动操作。

## 需求/问题描述

- 此前服务端有 `client:login` 登录通知（弹系统通知），但没有任何地方能看到"此刻有哪些客户端在线"；断开连接也没有事件通知本机 UI。`LatticeServer.sessions`（Map<token, AuthSession>）里已有数据，只缺暴露通道与 UI。

## 解决方案

1. **服务端核心**（`src/main/server/service.ts`）：
   - `AuthSession` 新增 `loginAt` 字段（登录时间，handleLogin 时记录）。
   - 新增公开方法 `listSessions()`：遍历 sessions 返回 `{ username, address, loginAt, lastSeen }`（address 复用 `remoteAddress()` 去 `::ffff:` 前缀）。
   - `socket.on('close')` 断开时经 `onLocalEvent` 发 `client:logout` 事件。防重技巧：用 `this.sessions.delete(session.token)` 的返回值判断会话是否仍在——`server.stop()` 已清空 sessions、客户端主动 `disconnect` RPC 均不会重复通知。
   - `disconnect` RPC 分支简化为只 `socket.close()`，会话清理与 logout 通知统一走 close 事件单一路径。
2. **主进程**（`src/main/index.ts`）：注册 `server:listSessions` IPC；`onLocalEvent` 中 `client:logout` 静默转发 `sendToAll('server:event', ev)`（不弹通知，仅驱动列表刷新）。
3. **预加载**（`src/preload/index.ts`）：`api.server.listSessions()`（`LatticeApi = typeof api` 类型自动传导到 index.d.ts）。
4. **渲染层**：
   - `src/shared/models.ts` 新增 `ServerSessionView` 类型（username/address/loginAt/lastSeen）。
   - `ServerView.vue` 新增「当前连接」页签（el-tabs，位于「服务控制」后）：el-table 展示账户/来源地址/登录时间/最近活跃/在线标签；无连接时 `el-empty` 区分「服务端未运行」与「暂无客户端连接」两种文案；订阅 `server:event` 收到 `client:login`/`client:logout` 即刷新列表，`onUnmounted` 取消订阅（`window.api.on` 返回取消函数）；挂载与 `pageActive` 可见时均拉取。

## 涉及文件

`src/main/server/service.ts`、`src/main/index.ts`、`src/preload/index.ts`、`src/shared/models.ts`、`src/renderer/src/main/views/ServerView.vue`

## 踩坑/设计结论

1. 防重复 logout：socket close 事件在 `server.stop()` 清空 sessions 后仍会触发，且客户端主动 disconnect RPC 原本会先 delete 再 close——统一用 `sessions.delete()` 返回值判断，只在真正移除时发事件，三条路径（网络断开 / server.stop / disconnect RPC）收敛为一条。
2. 会话级 `lastSeen` 仅在收到 RPC 时更新，列表"最近活跃"非秒级实时，属预期行为。
