# 悬浮球交互

> 归档日期：2026-11-27 ｜ 类型：缺陷处理（feedback），含需求开发（need） ｜ 来源：AI 编码会话（OpenCode + GLM） ｜ 梳理汇入时间：2026-11-27

## 用户提示词（原话，一字不改）

> 悬浮按钮点一下就没了

> 悬浮按钮点一下就没了，窗口缩小应该隐藏到托盘

> 悬浮按钮可以右键展示菜单：打开界面、传输、退出（现在感觉退出并没有完全退出）

## 实际需求梳理

1. 点击悬浮球不应消失（点击=展开主界面，悬浮球保持常驻）。
2. 主窗口最小化应隐藏到托盘（任务栏不留）。
3. 悬浮球右键弹原生菜单：打开界面 / 传输 / 退出；且退出必须真正完全退出。

## 问题原因与方案

### 1. 点击即消失（feedback）

- 根因：`FloaterApp.vue` 的 `openMain()` 是 `openMain() + closeFloater()` 两步，点击后悬浮球被 hide；`window:showFloater` 全工程无任何调用方，悬浮球一去不回。
- 修复：点击只 `window.api.window.openMain()`，删除 `closeFloater()` 调用。

### 2. 最小化隐藏到托盘

- `src/main/index.ts` 主窗口新增 `minimize` 事件：`mainWindow.hide()`（事件本身不可 `preventDefault`，「最小化即 hide」是标准做法，窗口从任务栏消失进托盘）。
- 踩坑：Electron 45 类型定义中 `minimize` 回调**无参数**，写 `(e) => e.preventDefault()` 会 TS2769/TS7006。

### 3. 右键菜单 + 完全退出（need）

- 新增 `window:floaterMenu` IPC（`src/main/index.ts`）：原生 `Menu.buildFromTemplate([...]).popup({ window: floaterWindow })`，无边框透明窗口里比 HTML 自绘稳。菜单项：
  - 打开界面 → `createMainWindow()`
  - 传输 → `createMainWindow()` + `sendToAll('nav:goto', 'transfers')`（新增跨页面导航事件，`App.vue` 监听白名单切换；主窗口刚创建渲染层未挂载时会丢事件，**延迟 800ms 重发兜底**）
  - 退出 → `quitApp()`
- **完全退出**：原托盘「退出」只 `app.quit()`，挂起的 socket/句柄可致进程残留、托盘留幽灵图标。新统一 `quitApp()`：`isQuitting = true` → `tray.destroy()` → `app.quit()` → 800ms 兜底 `setTimeout(() => app.exit(0), 800).unref?.()`。托盘菜单与悬浮球菜单共用。
- `FloaterApp.vue` 拖动/点击逻辑只认左键（`e.button !== 0` 直接 return），右键不会误触点击展开。

## 涉及文件
