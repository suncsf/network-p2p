# 菜单切换保活

> 归档日期：2026-11-27 ｜ 类型：需求开发（need） ｜ 来源：AI 编码会话（OpenCode + GLM） ｜ 梳理汇入时间：2026-11-27

## 用户提示词（原话，一字不改）

> 注意：切换工作区、传输等菜单，不可以刷新界面，要保持界面原有操作

## 实际需求梳理

侧栏切换菜单（工作区/传输/服务端/设置）不得重挂载组件：保留筛选 tab、滚动位置、表单内容等界面操作状态。

## 问题原因与方案

- 原状：仅工作区 `v-show` 常驻，传输/服务端/设置 `v-if`——切走销毁、切回重建（重拉数据、状态全丢）。
- 修复（`App.vue`）：四页全部 `v-show` 常驻，只挂载一次，切换仅显隐。
- **保活与数据新鲜度平衡**：常驻后数据只在启动时加载一次会变旧，给数据型页面加 `pageActive` prop + `watch`，重新可见时**轻量刷新数据**（不重置界面状态）：
  - `TransfersView.vue`：重拉待确认列表 + 传输记录（筛选 tab、速度采样不动）；
  - `ServerView.vue`：重拉服务端状态/账户/审计（页内 tab、弹窗状态不动）。

## 涉及文件

`src/renderer/src/main/App.vue`、`src/renderer/src/main/views/TransfersView.vue`、`src/renderer/src/main/views/ServerView.vue`

## 验证
