## 问题与修复（feedback）

1. **Electron 二进制缺失**：首次 `npm run dev` 报 `Error: Electron uninstall`，`node_modules/electron/dist` 和 `path.txt` 均缺失（此前依赖安装未下载成功）。修复：
   ```powershell
   $env:ELECTRON_MIRROR='https://npmmirror.com/mirrors/electron/'; node node_modules\electron\install.js
   ```
   （镜像已配在 .npmrc，但 npm 11+ 对 .npmrc 自定义键只告警不生效，故用环境变量。）
2. **electron-vite dev 不监听主进程**（详见 传输确认与进度.md）：主进程改动不重编译，dev 脚本加 `--watch` 修复。
3. **Windows 测试 EPERM**：41 项测试中 9 个失败，全是 `rmSync` 删临时目录报 `EPERM`——better-sqlite3 连接未关闭，Windows 不允许删除已打开文件（Linux 允许，故 Ubuntu 上不暴露）。修复：4 个测试文件（e2e/multi-client/p2p-e2e/transfer-store）清理前先 `db.close()`。教训：**Windows 上 SQLite 库连接必须先关再删目录**。
4. **npm 副作用**：Windows 上跑 npm 会改写 package-lock.json（删掉其他平台 optional 依赖、加 hasInstallScript），已还原不提交，避免影响 Ubuntu 侧安装。
