# 记住连接参数

> 归档日期：2026-11-27 ｜ 类型：需求开发（need） ｜ 来源：AI 编码会话（OpenCode + GLM） ｜ 梳理汇入时间：2026-11-27

## 用户提示词（原话，一字不改）

> 记住连接的参数

## 实际需求梳理

新建连接每次都要重输 IP/端口/账号/密码。要求记住连接参数：密码可选记住（加密存储，不落明文），再次打开连接表单自动填最近一次参数，点历史记录能带出记住的密码。

## 方案与实现（commit 47de6cb）

- **存储层**（`src/main/store.ts`）：local.db 迁移 v3，`connections` 表加 `password` 列（存 safeStorage 加密后的 base64 密文）；`saveConnection` 支持可选密码参数（undefined=保留旧值，null=清除）；`listConnections` 返回 `hasPassword`；新增 `getConnectionPassword(id)`。
- **主进程**（`src/main/index.ts`）：
  - `client:connect` 接受 `rememberPassword`，勾选且 `safeStorage.isEncryptionAvailable()` 时 `encryptString` 落库；显式 false 清除旧密码。
  - 新增 IPC `history:getPassword`：按 id 取密文 → `safeStorage.decryptString` 解密，不可解密返回空串。
- **preload**：`history.getPassword(id)`。
- **渲染层**（`ConnectView.vue`）：表单加「记住密码」勾选（默认勾选）；`onMounted` 自动填最近一次连接参数（含密码）；点历史记录 `fill()` 时带出记住的密码。

## 关键点

- safeStorage：Windows 走 DPAPI、Linux 走 libsecret，密文绑定当前系统用户，直接复制 local.db 到别的机器解不开。
- 迁移机制：`MIGRATIONS` 按 `local_meta.schema_version` 增量执行，老库自动升级。
