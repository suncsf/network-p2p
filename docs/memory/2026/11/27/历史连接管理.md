# 历史连接管理

> 归档日期：2026-11-27 ｜ 类型：需求开发（need），含缺陷处理（feedback） ｜ 来源：AI 编码会话（OpenCode + GLM） ｜ 梳理汇入时间：2026-11-27

## 用户提示词（原话，一字不改）

> Error invoking remote method 'client:reconnect': Error: 未记住密码，请在「新建连接」中连接一次并勾选「记住密码」 ，但是没有勾选啊

> 直接默认全部存储

> 无法关闭连接tab，和选择历史连接记录

## 实际需求梳理

1. **记住历史连接，可重新打开**：重启应用后工作区还原之前打开的连接选项卡；记住密码的自动重连，没记住的呈现「未连接」态并提供一键重连。
2. **密码默认全部存储**：不设「记住密码」勾选，连接成功一律加密记住。
3. **缺陷**：恢复出来的连接选项卡关不掉；「新建连接」弹窗里选不到历史连接记录。

## 方案与实现

### 启动恢复 + 一键重连（commit 7e8756b）

- `ConnectionManager`（`src/main/client/manager.ts`）新增 `addInactive()`：注册 `state: 'idle'` 的无 socket 连接项（仅 info，不建连接）；`connect()` 支持同 id 重连——先废弃旧 client，失败时选项卡不消失、标记错误态。
- 主进程（`src/main/index.ts`）：
  - `saveOpenConnections()` 把当前打开的连接（host/port/username）持久化到 `app_settings.openConnections`；connect/disconnect/重连时同步更新；
  - app 启动时读该列表还原选项卡：**记住密码的后台自动重连**，无密码的 idle 态呈现；
  - 新增 `client:reconnect` IPC：按 host/port/username 查记住的密码（store 新增 `getConnectionPasswordByKey`），用原 id 直连。
- `SessionView.vue`：非 connected 态加「重新连接」按钮（未记住密码时弹窗输入一次，输入后即被记住）。

### 密码默认全部存储（commit 4e70754）

- 去掉两个连接弹窗（`WorkspaceView.vue`/`ConnectView.vue`）的「记住密码」勾选框；连接成功、重连补输一律 safeStorage 加密落库（Windows DPAPI / Linux libsecret）。
- 根因教训：勾选框此前只加在已废弃的 `ConnectView.vue`，实际使用的 `WorkspaceView.vue` 弹窗从未记住过密码。

### 缺陷修复（feedback，commit 4e70754）

1. **恢复的选项卡无法关闭**：`manager.disconnect` 对无 socket 的连接直接 `return false`，info 未删。修复：无 socket 时仅移除 info。
2. **选不到历史连接**：带「最近连接」列表的 `ConnectView` 在多选项卡重构后**已完全不被引用**，历史选择 UI 丢失。修复：`WorkspaceView` 新建连接弹窗加回「最近连接」——点记录填入参数并带出记住的密码，「连接」按钮一键直连。
