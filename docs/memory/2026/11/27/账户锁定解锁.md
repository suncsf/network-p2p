# 账户锁定解锁

> 归档日期：2026-11-27 ｜ 类型：缺陷处理（feedback） ｜ 来源：AI 编码会话（OpenCode + GLM） ｜ 梳理汇入时间：2026-11-27

## 用户提示词（原话，一字不改）

> Error invoking remote method 'client:connect': Error: 账户已锁定，请稍后再试

## 实际需求梳理

客户端连接服务端报「账户已锁定」（连续 5 次密码错误触发、锁 5 分钟），且反复出现，需要找出反复锁定的根因并给出免等待的解除手段。

## 问题与根因（commit 821a12c）

**恶性循环**：客户端自动重连会用（错误的）密码按 1s/2s/4s… 退避**无限重试**——4 次重试即凑满 5 次失败把账户锁上；锁到期后下一次重试又记一次失败、再次锁上。只要应用开着，账户永远解不了。

## 解决方案

1. **根因修复**（`src/main/client/client.ts`）：登录遇到 `UNAUTHORIZED` / `LOCKED` / `FORBIDDEN` 等**鉴权类失败立即停止自动重连**（新增 `noRetry` 标志）——重试也不会成功，只会反复锁账户；连接选项卡呈红色错误态，等用户修正密码后手动「重新连接」（重连成功即记住新密码）。
2. **解锁入口**（`src/main/server/repo.ts` + `index.ts` + `preload` + `ServerView.vue`）：`accountRepo.unlock(id)` 清除失败计数与锁定时间；账户列表被锁账户显示红色「已锁定」标签（`lockedUntil > Date.now()`）+「解锁」按钮（`accounts:unlock` IPC），不用等 5 分钟自然到期。
3. 现场排查：直接用 better-sqlite3 查 lattice.db 的 `accounts` 表（`failed_attempts` / `locked_until` 字段）确认当时已自然解锁；锁也可能发生在 Ubuntu 端自己的服务端账户。
