# 文件列表视图右键菜单

> 归档日期：2026-11-26 ｜ 类型：需求开发（need） ｜ 来源：AI 编码会话（OpenCode + GLM） ｜ 梳理汇入时间：2026-11-26 17:07

## 用户提示词（原话，一字不改）

> 新增列表展示和卡片展示模式，增加右键菜单操作

（澄清问答：范围三选一「传输面板 / 文件列表页 / 两处都加」，用户选择**文件列表页**）

## 实际需求梳理

- 文件浏览页（FilesView）的文件/目录支持两种展示模式：列表（现有表格）与卡片（图标网格），可切换且记忆偏好。
- 右键菜单提供文件操作：打开/下载/P2P 传输/重命名/删除/复制路径，空白区域右键提供上传/新建文件夹/刷新。

## 方案与实现

- **新组件 `src/renderer/src/components/ContextMenu.vue`**：teleport 到 body 的浮层菜单；位置按菜单实际尺寸夹取避免超出视口；捕获阶段监听 document 的 mousedown/contextmenu/keydown/scroll/resize 实现外点、Esc、滚动、右击其他区域自动关闭；行内右键 preventDefault 重新打开不冲突。菜单项类型抽出为 `context-menu.ts`（`ContextMenuItem`：label/icon/danger/disabled/divider/action）。
- **FilesView**：
  - 工具栏 `el-radio-group` 切换「列表/卡片」（Expand/Grid 图标），偏好存 `localStorage['lattice.files.viewMode']`；
  - 卡片网格：`repeat(auto-fill, minmax(150px, 1fr))`，hover 高亮，名称超长省略 + title 全名，点击进入目录，空目录 el-empty；
  - 列表视图行右键走 `el-table` 的 `@row-contextmenu`（组件回调需手动 preventDefault）+ 根级 `@contextmenu.prevent` 兜底空白区（以 `defaultPrevented` 区分行/空白）；
  - 菜单项按权限（READ/TRANSFER/RENAME/DELETE/UPLOAD/WRITE）自动禁用，删除为红色危险项；「复制路径」用 `navigator.clipboard.writeText` 复制 `授权根目录/相对路径`。

## 踩坑结论

1. 组件导入路径：views 在 `src/renderer/src/main/views/`，共享组件在 `src/renderer/src/components/`，需 `../../components/...`，写 `../components` 报 TS2307。
2. Vue `<script setup>` 不能直接 export 类型 → 菜单项接口放独立 `context-menu.ts`。
3. Element Plus 2.14 的 `el-radio-button` 用 `value` prop（SessionView 已有同样写法，风格一致）。
