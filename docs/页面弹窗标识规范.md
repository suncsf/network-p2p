# 页面/弹窗标识标签规范（Lattice 落地版）

> 源规范：通用「页面/弹窗标识标签规则」。本文记录其在本项目的适配差异与登记表；
> 实现代码为唯一事实来源：`src/renderer/src/composables/usePageRegistry.ts`。

## 1. 本项目适配差异

| 项 | 通用规范 | 本项目 |
|---|---|---|
| 页面承载 | AppLayout cachedPage()（vue-router + keep-alive） | 无路由，`App.vue` 直接切视图；PageWrapper 统一包装（workspace 用 v-show 常驻 ≈ keep-alive，server/settings 用 v-if） |
| 徽章位置 | left: 248px（220 侧边栏 + 28） | **left: 228px**（本项目侧边栏 200px），bottom: 16px，PageWrapper 渲染 |
| ID 持久化路径 | forall/config/page-id-store.json | **userData/config/page-id-store.json**（主进程 `src/main/ipc/page-id.handler.ts`） |
| AI 注入 | chat store 调 getPageRegistrySnapshot() | 本项目暂无 AI/chat 模块，快照 API 已就绪（`usePageRegistry.ts` → `getPageRegistrySnapshot()`） |
| 登录页特殊处理 | LoginLayout 自渲染徽章 | 本项目无登录页 |
| 悬浮球窗口 | — | 独立窗口（FloaterApp），不属于页面注册体系 |

## 2. 固定 ID 登记表（当前）

页面（`FIXED_PAGE_IDS`，新增顺延最大值 + 1，空缺不回补）：

| ID | routeName | 名称 |
|---|---|---|
| #a001 | workspace | 工作区 |
| #a002 | server | 服务端 |
| #a003 | settings | 设置 |

弹窗（`FIXED_DIALOG_IDS`，dialogKey = '页面::语义名'）：

| ID | dialogKey | 名称 |
|---|---|---|
| #a001b001 | workspace::new-connection | 新建连接 |
| #a002b001 | server::account-create | 新建账户 |
| #a002b002 | server::grant-add | 添加可访问目录 |
| #a002b003 | server::node-permission | 编辑权限树 |

说明：

- SessionView / FilesView / TransfersView / ConnectView 为连接会话内嵌视图或未挂载组件，不注册页面级标识。
- FilesView 内的 `ElMessageBox.prompt`（新建文件夹/重命名）为全局消息框，非业务弹窗，不注册。
- 新增弹窗：宿主在 `PAGE_DIALOG_BASE` 内时无需硬编码，自动派生稳定 ID 并固化到 page-id-store.json；需与文档对照引用的关键弹窗再登记 `FIXED_DIALOG_IDS`。
- 未命中任何表的 dialogKey 走随机兜底，页段取 a800~afff 高位区间（避开固定表顺延范围），按 key 固化、永久复用。

## 3. 落地文件清单

| 文件 | 职责 |
|---|---|
| src/renderer/src/composables/usePageRegistry.ts | 注册中心：固定表/解析/注册/注销/快照/启动加载固化映射 |
| src/renderer/src/components/PageIdBadge.vue | 徽章：显示 #xxxx，点击复制 |
| src/renderer/src/components/PageWrapper.vue | 页面包装器：自动注册 + 左下角徽章（仅 App.vue 使用） |
| src/renderer/src/main/App.vue | 布局层：三个视图统一 PageWrapper 包装 |
| src/main/ipc/page-id.handler.ts | 主进程：page-id-store.json 读写，IPC `page-id:load` / `page-id:save` |
| src/preload/index.ts | `window.api.pageId.{load,save}` |

弹窗接线模式（本项目实践，等价于规范的「手动注册/注销 + header 徽章」）：

```ts
const xxxPageId = ref('')
watch(xxxVisible, (visible) => {
  if (visible) xxxPageId.value = registerDialog('弹窗名', '页面::语义名')
  else if (xxxPageId.value) { unregisterDialog(xxxPageId.value); xxxPageId.value = '' }
})
```

`watch(visible)` 覆盖取消/确定/右上角 X/ESC 全部关闭路径，无需逐个 close 函数补注销。

## 4. 新增页面/弹窗 Checklist

新增视图页面：

- [ ] `usePageRegistry.ts` 的 `FIXED_PAGE_IDS` / `PAGE_DIALOG_BASE` 登记 `'新视图名': 'aXXX'`（顺延最大值 + 1）
- [ ] App.vue 用 PageWrapper 包装该视图（页面组件内禁止再包 PageWrapper，否则徽章叠印 + 注册表同页两条）
- [ ] 页面根节点保持普通 div

新增弹窗：

- [ ] `registerDialog('名称', '视图名::语义名')`，`watch(visible)` 统一注册/注销并清空 ref
- [ ] `el-dialog` 的 `#header` 插槽内标题旁放 `<PageIdBadge :page-id="xxxPageId" />`（标题从 title 属性移入 header）
- [ ] 需要硬编码序号时登记 `FIXED_DIALOG_IDS`

验证（本项目命令，替代通用规范中 eslint 项——项目暂未配置 eslint）：

- [ ] `npm run typecheck` 无新增错误
- [ ] `npx electron-vite build` 构建通过
- [ ] 运行时确认：页面左下角仅一个徽章且与固定表一致；弹窗开→徽章出现、关→注册表消失（可 `grep "a00X" src/renderer/src/composables/usePageRegistry.ts` 反查）

## 5. 人工反查

1. `grep "aXXX" src/renderer/src/composables/usePageRegistry.ts`（FIXED_PAGE_IDS / FIXED_DIALOG_IDS / PAGE_DIALOG_BASE）
